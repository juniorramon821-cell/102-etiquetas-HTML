102 Etiquetas HTML

Página educativa que muestra 102 etiquetas HTML, su descripción, ejemplo de uso y un elemento adicional.

Listado de las 102 etiquetas HTML

A continuación se presentan 102 etiquetas HTML diferentes con ejemplos de uso.

N.º Nombre de la etiqueta Descripción Ejemplo de cómo usar Elemento adicional
1 <html> Es el elemento raíz que contiene todo el documento HTML. <html lang="es"> Normalmente contiene head y body.
2 <head> Contiene información y configuraciones del documento. <head> ... </head> Puede contener title, meta, link y style.
3 <title> Define el título que aparece en la pestaña del navegador. <title>Mi página</title> Aparece en la pestaña del navegador.
4 <link> Permite relacionar el documento con recursos externos. <link rel="stylesheet" href="styles.css"> Se utiliza frecuentemente para CSS.
5 <meta> Define información adicional sobre el documento. <meta charset="UTF-8"> Ayuda con la codificación y configuración de la página.
6 <style> Permite escribir reglas CSS dentro del documento HTML. <style>body { color: blue; }</style> Se recomienda CSS externo para proyectos grandes.
7 <body> Contiene el contenido visible de la página. <body>Contenido</body> Es el cuerpo principal del documento.
8 <h1> Define el encabezado principal. <h1>Título principal</h1> Normalmente se utiliza para el título principal.
9 <h2> Define un encabezado de segundo nivel. <h2>Subtítulo</h2> Se utiliza debajo de h1.
10 <h3> Define un encabezado de tercer nivel. <h3>Tema</h3> Puede utilizarse para organizar secciones.
11 <h4> Define un encabezado de cuarto nivel. <h4>Subtema</h4> Permite crear una jerarquía de títulos.
12 <h5> Define un encabezado de quinto nivel. <h5>Apartado</h5> Es un encabezado de menor nivel.
13 <h6> Define el encabezado de menor nivel. <h6>Detalle</h6> Es el sexto nivel de encabezado.
14 <p> Define un párrafo de texto. <p>Hola mundo</p> Es una de las etiquetas de texto más utilizadas.
15 <br> Inserta un salto de línea. Hola<br>Mundo No necesita etiqueta de cierre.
16 <hr> Representa una separación temática. <hr> Normalmente aparece como una línea horizontal.
17 <div> Es un contenedor genérico para organizar contenido. <div>Contenido</div> Se utiliza mucho para estructurar páginas.
18 <span> Es un contenedor genérico para contenido en línea. <span>Texto</span> Es útil para aplicar estilos a una parte del texto.
19 <a> Permite crear enlaces. <a href="https://example.com">Visitar</a> Utiliza el atributo href.
20 <img> Permite insertar imágenes. <img src="foto.jpg" alt="Foto"> El atributo alt describe la imagen.
21 <figure> Representa contenido independiente como una imagen o gráfico. <figure>...</figure> Puede contener figcaption.
22 <figcaption> Define el texto descriptivo de una figura. <figcaption>Imagen de ejemplo</figcaption> Normalmente se utiliza dentro de figure.
23 <audio> Permite insertar contenido de audio. <audio controls></audio> Puede utilizar controls.
24 <video> Permite insertar videos. <video controls></video> Puede mostrar controles de reproducción.
25 <source> Define una fuente alternativa para audio o video. <source src="video.mp4" type="video/mp4"> Se utiliza dentro de audio o video.
26 <track> Define pistas de texto para videos. <track kind="subtitles" src="subtitulos.vtt"> Puede utilizarse para subtítulos.
27 <iframe> Permite insertar otra página o contenido externo. <iframe src="pagina.html"></iframe> Puede mostrar mapas, videos y otras páginas.
28 <canvas> Define un área para dibujar mediante JavaScript. <canvas width="300" height="150"></canvas> Puede utilizarse para gráficos.
29 <svg> Permite utilizar gráficos vectoriales escalables. <svg width="100" height="100"></svg> Es útil para gráficos y dibujos.
30 <ul> Crea una lista sin orden numérico. <ul><li>Pan</li></ul> Normalmente muestra viñetas.
31 <ol> Crea una lista ordenada. <ol><li>Primero</li></ol> Normalmente utiliza números.
32 <li> Define un elemento dentro de una lista. <li>Producto</li> Se utiliza dentro de ul u ol.
33 <dl> Define una lista de descripción. <dl>...</dl> Se combina con dt y dd.
34 <dt> Define un término dentro de una lista de descripción. <dt>HTML</dt> Se utiliza dentro de dl.
35 <dd> Define la descripción de un término. <dd>Lenguaje de marcado</dd> Normalmente acompaña a dt.
36 <menu> Representa un conjunto de opciones o elementos de menú. <menu><li>Inicio</li></menu> Puede utilizarse para listas de comandos.
37 <table> Permite crear una tabla de datos. <table>...</table> Puede contener filas y columnas.
38 <caption> Define el título o descripción de una tabla. <caption>Ventas</caption> Normalmente se coloca dentro de table.
39 <colgroup> Agrupa columnas de una tabla. <colgroup>...</colgroup> Permite aplicar características a columnas.
40 <col> Representa una columna dentro de un grupo de columnas. <col span="2"> Se utiliza dentro de colgroup.
41 <thead> Agrupa las filas que representan el encabezado de una tabla. <thead><tr>...</tr></thead> Se utiliza para organizar tablas.
42 <tbody> Agrupa el contenido principal de una tabla. <tbody>...</tbody> Contiene normalmente las filas de datos.
43 <tfoot> Agrupa las filas finales de una tabla. <tfoot>...</tfoot> Puede utilizarse para totales.
44 <tr> Define una fila de una tabla. <tr>...</tr> Contiene th o td.
45 <th> Define una celda de encabezado de una tabla. <th>Nombre</th> Normalmente aparece resaltada.
46 <td> Define una celda de datos de una tabla. <td>Juan</td> Contiene los datos de la tabla.
47 <form> Define un formulario para recibir información del usuario. <form>...</form> Puede contener campos de entrada.
48 <label> Define una etiqueta descriptiva para un campo de formulario. <label>Nombre:</label> Puede asociarse con input mediante for.
49 <input> Permite introducir diferentes tipos de datos. <input type="text"> Puede ser texto, número, fecha, correo, etc.
50 <button> Crea un botón interactivo. <button>Enviar</button> Puede ejecutar acciones con JavaScript.
51 <select> Crea una lista desplegable. <select>...</select> Normalmente contiene option.
52 <option> Define una opción dentro de una lista desplegable. <option>Santo Domingo</option> Se utiliza normalmente dentro de select.
53 <optgroup> Agrupa opciones relacionadas dentro de un select. <optgroup label="Frutas"> Permite organizar muchas opciones.
54 <textarea> Permite introducir texto de varias líneas. <textarea>Escriba aquí</textarea> Es útil para comentarios y mensajes.
55 <datalist> Proporciona opciones sugeridas para un campo input. <datalist id="ciudades">...</datalist> Se puede asociar mediante el atributo list.
56 <fieldset> Agrupa controles relacionados de un formulario. <fieldset>...</fieldset> Puede contener legend.
57 <legend> Define el título de un fieldset. <legend>Datos personales</legend> Ayuda a identificar el grupo de campos.
58 <output> Representa el resultado de un cálculo o acción. <output>100</output> Puede actualizarse mediante JavaScript.
59 <progress> Muestra el progreso de una tarea. <progress value="70" max="100"></progress> Representa un porcentaje de progreso.
60 <meter> Representa una medida dentro de un rango conocido. <meter value="7" min="0" max="10"></meter> Puede utilizarse para mostrar niveles o puntuaciones.
61 <details> Crea un bloque de información que puede abrirse y cerrarse. <details>Información</details> Normalmente se utiliza junto con summary.
62 <summary> Define el título visible de un elemento details. <summary>Más información</summary> El usuario puede hacer clic para mostrar contenido.
63 <dialog> Representa una ventana de diálogo. <dialog open>Hola</dialog> Puede utilizarse para ventanas emergentes.
64 <header> Representa la cabecera de una página o sección. <header>Encabezado</header> Puede contener títulos y navegación.
65 <nav> Representa una sección de navegación. <nav><a href="#">Inicio</a></nav> Se utiliza para menús y enlaces principales.
66 <main> Representa el contenido principal del documento. <main>Contenido principal</main> Normalmente debe existir un main principal.
67 <section> Representa una sección temática del documento. <section>Noticias</section> Ayuda a organizar el contenido.
68 <article> Representa contenido independiente. <article>Artículo</article> Puede utilizarse para noticias o publicaciones.
69 <aside> Representa contenido relacionado pero secundario. <aside>Publicidad</aside> Puede utilizarse como barra lateral.
70 <footer> Representa el pie de página o de una sección. <footer>Derechos reservados</footer> Puede contener información de contacto.
71 <address> Representa información de contacto. <address>Santo Domingo, RD</address> Puede contener dirección o contacto.
72 <strong> Indica que un texto tiene gran importancia. <strong>Importante</strong> Normalmente se muestra en negrita.
73 <em> Indica énfasis en un texto. <em>Texto importante</em> Normalmente aparece en cursiva.
74 <b> Representa texto al que se quiere llamar la atención visualmente. <b>Texto destacado</b> Normalmente aparece en negrita.
75 <i> Representa texto con una voz o estado diferente. <i>Palabra</i> Normalmente aparece en cursiva.
76 <u> Representa texto que debe distinguirse visualmente. <u>Texto subrayado</u> Normalmente se muestra subrayado.
77 <s> Representa información que ya no es válida o relevante. <s>RD$500</s> Normalmente aparece tachado.
78 <mark> Resalta una parte del texto. <mark>Importante</mark> Normalmente aparece resaltado.
79 <small> Representa texto secundario o de menor importancia. <small>Nota adicional</small> Normalmente se muestra más pequeño.
80 <sub> Representa texto como subíndice. H<sub>2</sub>O El número aparece debajo de la línea.
81 <sup> Representa texto como superíndice. x<sup>2</sup> El número aparece arriba de la línea.
82 <del> Representa texto que ha sido eliminado. <del>Texto eliminado</del> Normalmente aparece tachado.
83 <ins> Representa texto que ha sido agregado. <ins>Texto nuevo</ins> Normalmente aparece subrayado.
84 <code> Representa un fragmento de código informático. <code>console.log("Hola");</code> Normalmente utiliza una fuente monoespaciada.
85 <pre> Representa texto preformateado. <pre>Texto con espacios</pre> Conserva espacios y saltos de línea.
86 <kbd> Representa una entrada del teclado. <kbd>Ctrl</kbd> + C Se utiliza para indicar teclas.
87 <samp> Representa una salida de ejemplo de un programa. <samp>Error 404</samp> Se utiliza para mostrar resultados de programas.
88 <var> Representa una variable matemática o de programación. <var>x</var> Puede utilizarse en fórmulas.
89 <blockquote> Representa una cita extensa de otra fuente. <blockquote>Una cita</blockquote> Puede incluir el atributo cite.
90 <q> Representa una cita corta dentro de un texto. <q>Hola mundo</q> El navegador puede mostrar comillas.
91 <cite> Representa el título de una obra o referencia. <cite>Don Quijote</cite> Puede utilizarse para libros y obras.
92 <abbr> Representa una abreviatura o acrónimo. <abbr title="HyperText Markup Language">HTML</abbr> El atributo title puede mostrar la explicación.
93 <time> Representa una fecha u hora. <time datetime="2026-10-06">6 de octubre</time> Puede utilizar el atributo datetime.
94 <data> Relaciona un contenido visible con un valor legible por máquinas. <data value="123">Producto</data> Es útil para asociar valores a datos visibles.
95 <bdi> Aísla una parte de texto cuya dirección puede ser diferente. <bdi>Usuario</bdi> Es útil con idiomas de escritura bidireccional.
96 <bdo> Permite establecer explícitamente la dirección del texto. <bdo dir="rtl">Texto</bdo> Puede utilizarse para texto de derecha a izquierda.
97 <ruby> Representa anotaciones de pronunciación o explicación. <ruby>漢字</ruby> Se utiliza especialmente con idiomas asiáticos.
98 <rt> Define el texto de una anotación ruby. <ruby>漢<rt>kan</rt></ruby> Normalmente aparece dentro de ruby.
99 <rp> Proporciona paréntesis alternativos para navegadores que no soportan ruby. <rp>(</rp> Se utiliza junto con ruby y rt.
100 <wbr> Indica un posible punto de salto de línea. super<wbr>palabra Es útil para palabras o textos muy largos.
101 <script> Permite incluir o enlazar código JavaScript. <script src="script.js"></script> Permite agregar interactividad a la página.
102 <noscript> Contiene contenido que se muestra cuando JavaScript está desactivado o no es compatible. <noscript>JavaScript está desactivado.</noscript> Sirve como alternativa cuando JavaScript no funciona.
